# Hoyo en Uno Pro Shop · Web vitrina (fase 1)

Maqueta de la web vitrina: marca, tiendas, catálogo con pedidos por WhatsApp, torneos y contacto.
Sitio estático (un solo `index.html`), listo para desplegar en Vercel sin configuración.

## Editar
- **Colores:** variables `--brand`, `--brand-2`, `--accent`, `--bg`, `--night` en `:root`.
- **Logo:** `<symbol id="logo">` al inicio del `<body>`.
- **Tiendas y WhatsApp:** objeto `TIENDAS` en el `<script>` final.
- **Productos:** arreglo `PRODUCTOS` en el mismo `<script>`.

Fotos de muestra de Unsplash; se reemplazan por las fotos reales. La página lleva `noindex` mientras sea maqueta.
